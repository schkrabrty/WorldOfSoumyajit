Biometric Voting System using Adhar Card in India

Soumyajit Chakraborty 1, {% include person.html id="siddhartha_mukherjee" name="Siddhartha Mukherjee" %} 1, {% include person.html id="bhaswati_sadhukhan" name="Bhaswati Sadhukhan" %} 1, {% include person.html id="kazi_tanvi_yasmin" name="Kazi Tanvi Yasmin" %} 1
1 Narula Institute of Technology

The paper will give an overview of a Biometric Voting System (BVS) which will access the data stored in the database of Adhar card, a Government Id card for each citizen in India, while casting their votes. While issuing the Adhar card a citizen of India needs to give his/her unique biometric data i.e. the fingerprint image and iris image of both eyes to the government. The BVS is integrated with a biometric fingerprint machine for the authentication of a genuine voter on the Election Day by comparing the given image with the already stored fingerprint image of that voter in the Adhar card database. This system has been developed in Microsoft Visual Studio 2015 with the help of ASP.NET, C# and SQL Server 2014. To eradicate the evil of vote rigging now-a-days in several elections in India, this proposed system can be implemented to get a transparent election in future.

In this work, I developed a biometric-enabled voting system for India, where a voter would be authenticated based on his/her fingerprint and the data, accessed from the database of a government ID card called the Adhar Card. You can find the paper here.
