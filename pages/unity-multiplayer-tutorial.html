Multiplayer Tutorials for Students of the Projects in Virtual Reality Design (CS-4249/5249) Course

A compilation of all the tutorials that we created for the students as Graduate Teaching Assistants

In 2026, {% include person.html id="yuanhao_lyu" name="Frank" new_tab=true %} and I developed a tutorial on building multiplayer VR applications in Unity using Photon Fusion and the Unity XR Interaction Toolkit. It guides students through multiplayer sessions, networked avatars, shared object interactions, managing ownership transfer, implementing remote procedure callbacks, and voice communication. Along with my lab mates {% include person.html id="yuanhao_lyu" name="Frank" new_tab=true %} and {% include person.html id="sodabe_bandali" name="Sodabe" new_tab=true %}, we delivered a lecture to help students get started with networking in Unity. The project and written guide are available here. During the same semester, I also created and taught a tutorial on setting up Unity and Visual Studio Code, to help students configure both tools for their course projects. The setup guide is available here.

In Fall 2025, I created a tutorial on building multiplayer VR applications using Photon Fusion and the Meta XR SDK in Unity Game Engine. It introduced students to key concepts such as setting up a Photon Fusion project, synchronizing networked objects, managing ownership transfer, and implementing remote procedure callbacks. Along with my lab mates {% include person.html id="yuanhao_lyu" name="Frank" new_tab=true %} and {% include person.html id="sodabe_bandali" name="Sodabe" new_tab=true %}, we delivered two lectures and a setup video to help students get started. All materials are available here.

In Fall 2023, I created a tutorial on developing multiplayer VR applications using Photon PUN2 and the Unity XR Interaction Toolkit in Unity Game Engine, instead of using Photon Fusion and the Meta XR SDK (as Photon Fusion was pretty new back then). The tutorial covered essentials such as setting up a Photon PUN2 project, synchronizing networked objects, managing ownership transfer, and implementing remote procedure callbacks. Together with {% include person.html id="yuanhao_lyu" name="Frank" new_tab=true %}, we delivered one lecture and a setup video to help students get started. All materials are available here.

In Fall 2020, during the COVID-19 lockdown, students couldn’t collaborate in person to build VR games. To adapt, we focused on developing multiplayer computer games playable remotely while comparing the Photon PUN2 and Mirror network plugins. I created tutorials for both in the Unity Game Engine, covering project setup, object synchronization, ownership transfer, and remote procedure callbacks. All related materials for Photon PUN2 and Mirror are available here and here, respectively. We ultimately chose Photon PUN2 for future courses because it offered greater customization and extensive online support resources for students.
